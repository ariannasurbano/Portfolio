The app features a searchable recipe library with ingredient lists, preparation tips, and meal ideas, while the layout is built for mobile and desktop use so people can quickly access recipes while they cook.

Corner 22's Billing System

Corner 22's Billing System is a point-of-sale application created to handle dine-in and digital orders for a small restaurant or cafe. It supports both cash transactions and GCash payments, making checkout easier for staff and customers.

The system stores every transaction in a database, which helps reduce manual errors and keeps sales records organized. It includes clear input fields for menu items, order quantities, and payment details so the team can move quickly during busy periods.

This project emphasizes fast order handling, transparent receipt creation, and sales reporting. It aims to improve daily operations by making order management more reliable and reducing the risk of lost or misplaced transaction details.

Happy Net Cafe — PC Monitoring & Management

Happy Net Cafe is a PC shop management project created to give owners full visibility of their computer stations. It tracks active sessions, seat availability, and time usage so managers can quickly see which computers are occupied.

The system includes session timers and billing summaries, making it easier to charge customers accurately and avoid manual calculations. It also improves the customer experience by reducing wait times and keeping the shop layout organized.

Designed with simplicity in mind, the app uses intuitive dashboards and clear monitoring screens. This helps shop staff respond faster to new customers, track session changes, and generate daily reports for revenue and usage patterns.
